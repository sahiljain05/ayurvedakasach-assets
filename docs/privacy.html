This policy explains how Ayurveda Ka Sach ("we") and our tool Ayurveda Ka Sach Uploader (the "API Client") handle information. Ayurveda Ka Sach is operated by Sahil Jain, an individual.

1. What the API Client does

The API Client uses YouTube API Services (YouTube Data API v3) for one purpose: uploading our own finished short videos, with their title and description, to our own YouTube channel @ayurvedakasach. It runs on our own server and is used only by the channel owner. It has no public sign-up and no other users.

2. Information we access, collect and store

  • Access: through Google OAuth 2.0, the API Client is authorised by the channel owner with the youtube.upload scope. It uses this only to call videos.insert (and to read back the upload status of videos it uploaded).
  • Stored: an OAuth refresh token for our own channel, kept in a private file on our server that only the uploader process can read; and the IDs of videos we uploaded, kept in our upload log.
  • Not collected: we do not collect, store or process personal data of any other YouTube user — no viewer data, comments, subscriber lists or analytics of other people.

3. How we use and share information

The information above is used only to upload our videos and to confirm that each upload succeeded. We do not sell, rent or share it with anyone, and we do not use it for advertising. We do not place cookies or tracking on this website.

4. YouTube and Google

The API Client uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

5. Revoking access and deleting data

Access granted to the API Client can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions. When access is revoked, or on request, we delete the stored refresh token immediately and delete our upload log within 7 days. Stored API data is refreshed or deleted at least every 30 days as required by the YouTube API Services policies.

6. Social media pages

We also publish the same clips on Instagram and Facebook. Those platforms' own privacy policies apply when you view or interact with our posts there.

7. Contact

Questions or deletion requests: ayurvedakasach@gmail.com.

8. Changes

We will update this page if our practices change and revise the "Last updated" date above.
